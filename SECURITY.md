# Security Policy

This is a public portfolio repository. Please do not open public issues for security-sensitive reports.

## Reporting a Vulnerability

If you notice a security problem, contact the repository owner privately:

```text
samithchandula@gmail.com
```

Please include:

- What you found
- The affected file, page, dependency, or workflow
- Steps to reproduce, if applicable
- Any suggested fix

## Repository Safety Notes

- Do not commit secrets, access tokens, private keys, `.env` files, or private documents.
- All portfolio content should be reviewed before it is merged into `main`.
- GitHub Pages deployment should run only from the protected `main` branch.
